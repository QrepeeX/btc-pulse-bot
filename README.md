# BTC Pulse — Telegram Mini App «BTC за 5 минут»

Мини-приложение в Telegram: рос или упал BTC за последние 5 минут, с графиком.
Без сервера: статический сайт на GitHub Pages + одноразовый скрипт, который настраивает кнопку меню бота.
Данные браузер берёт напрямую из публичного API Binance (запасной источник — Bybit).

## Требуется VPN

Binance и Bybit блокируют часть регионов (в т.ч. РФ), а у ряда провайдеров режутся и сами запросы к ним.
Если у клиента нет VPN, график не загрузится: приложение покажет явную ошибку и кнопку «Повторить».
Приложение само переключается на Bybit, если Binance недоступен 5 секунд, и раз в 60 секунд пробует вернуться.
Telegram и github.io должны открываться; если нет, нужен VPN на всём устройстве, а не только в Telegram.

## Структура

- `webapp/` — сайт (HTML/CSS/JS, график lightweight-charts лежит в `webapp/vendor/`).
- `scripts/setup-bot.mjs` — настройка бота (кнопка меню, описание).
- `tests/` — тесты (`node --test`).
- `.github/workflows/pages.yml` — проверка на токены, тесты, деплой на Pages.

## 1. Создать бота в BotFather

1. Открой [@BotFather](https://t.me/BotFather), команда `/newbot`.
2. Задай имя и username (оканчивается на `bot`).
3. Скопируй токен. Он нужен только в `.env` (шаг 3), больше нигде.

## 2. Репозиторий и GitHub Pages

1. Создай **публичный** репозиторий на GitHub и запушь проект в ветку `main`.
2. Settings → Pages → **Source: GitHub Actions**.
3. После первого пуша дождись зелёного workflow «Deploy to GitHub Pages».
4. Адрес приложения: `https://<логин>.github.io/<репозиторий>/`.

## 3. Настроить .env

```
cp .env.example .env
```

Заполни:

- `BOT_TOKEN` — токен от BotFather.
- `WEBAPP_URL` — адрес из шага 2, строго `https://`.

`.env` в `.gitignore`. Не коммить его и не вставляй токен в код, README и чаты.

## 4. Настроить бота

Нужен Node.js 22+, зависимости не нужны.

```
node scripts/setup-bot.mjs
```

Скрипт ставит кнопку меню «Открыть график», описание бота и пустой список команд, затем проверяет результат через `getMe` и `getChatMenuButton`.
Повторный запуск безопасен. Токен в выводе маскируется.
Коды выхода: `0` — ок, `1` — ошибка конфига (нет токена, URL не https), `2` — ошибка Telegram API.

Открой бота в Telegram: внизу будет кнопка «Открыть график». На `/start` бот молчит, так и задумано.
По желанию через BotFather `/newapp` можно получить ссылку вида `t.me/<бот>?startapp`.

## Локальный просмотр

Режим `?mock=1` подставляет случайные данные, интернет и VPN не нужны.

```
npx serve webapp
```

или

```
py -m http.server 8080 --directory webapp
```

Открой `http://localhost:3000/?mock=1` (для `serve`) или `http://localhost:8080/?mock=1`.
Без `?mock=1` приложение берёт живые данные Binance (нужен доступ к ним).

## Тесты

```
node --test tests/
```

Эти же тесты гоняет CI перед деплоем: упал тест — деплоя не будет.

## CI/CD

Workflow на каждый пуш в `main`:

1. **secret-scan** — ищет в репозитории шаблон токена Telegram (`.env.example` исключён). Нашёл — падает.
2. **test** — `node --test tests/` на Node 22.
3. **deploy** — публикует `webapp/` на GitHub Pages (права `pages: write`, `id-token: write`).

## Заметки по гео-блокировкам

- `data-api.binance.vision` и `data-stream.binance.vision` — публичные эндпоинты только для рыночных данных. В некоторых странах они недоступны (HTTP 451 или обрыв соединения).
- Bybit бывает недоступен там же; если доступен, подпись внизу покажет «Источник: Bybit».
- Если Bybit не отдаёт историю из-за CORS, график копится из потока, пока висит баннер «Накопление данных».
- Результаты проверок из РФ с VPN и без, а также внутри Telegram, записывай сюда после тестового прогона:
  - Binance REST/CORS: _не проверено_
  - Binance WS: _не проверено_
  - Bybit REST/WS: _не проверено_
  - Открытие github.io в Telegram: _не проверено_

## Передача бота клиенту (Transfer Ownership)

1. В [@BotFather](https://t.me/BotFather): `/mybots` → выбери бота → **Bot Settings** → **Transfer Ownership**.
2. Укажи аккаунт клиента, который должен принять передачу.
3. После передачи старый токен перестаёт работать, клиент получает новый. Если репозиторий остаётся у тебя, новый токен в нём не нужен: скрипт настройки запускается один раз.
4. Если URL приложения меняется (новый репозиторий или аккаунт GitHub), клиент запускает `node scripts/setup-bot.mjs` с новым `WEBAPP_URL`.

## Источники и лицензии

- График: [TradingView Lightweight Charts](https://www.tradingview.com/lightweight-charts/) (Apache-2.0), требует атрибуции в футере.
- Курс: BTCUSDT spot, $ ≈ USDT.
